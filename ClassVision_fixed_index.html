Privacy & settings

Student details and attendance records are stored in this browser's local storage and are not uploaded to a server by this app. Anyone with access to this browser profile may be able to access them. Clearing browser site data may erase them.

This version intentionally does not perform face recognition. Use a student ID or supervised roll-number check to avoid automatic misidentification. A teacher should supervise attendance changes.
